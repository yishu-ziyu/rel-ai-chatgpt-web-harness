Before you start Use the OpenAI organization and ChatGPT workspace where you will use Rel.AI. You need access to create or use a Secure MCP Tunnel in that organization.
1
Create your Secure MCP Tunnel

Set the tunnel to the OpenAI organization and ChatGPT workspace where you will use Rel.AI.

In OpenAI, complete all tunnel fields: Name, Description, Organizations, and ChatGPT workspaces. Select each organization and ChatGPT workspace where you will use Rel.AI.

Copy the ID that starts with tunnel_.

Having trouble?

Make sure the tunnel belongs to the OpenAI organization you intend to use and is associated with the ChatGPT workspace where you use Rel.AI.

If you cannot create or edit tunnels, your OpenAI organization owner may need to grant you tunnel access.

2
Create a runtime API key

Create it in the same OpenAI organization as your tunnel, then copy it while OpenAI still shows it.

Stored securely on this computer.

About the runtime API key

Use a restricted API key from the same OpenAI organization as the tunnel and allow it to access the tunnel.

Rel.AI uses this key only to operate this Secure MCP Tunnel. It is encrypted by your operating system and is never shown again after you save it.
